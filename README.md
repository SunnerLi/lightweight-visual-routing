# Towards Lightweight Visual Routing for Mobile Agents via Fine-Grained Screenshot Synthesis

This repository hosts the project page for our paper, presented at the
**NeurIPS 2026 Workshop on On-Device Intelligence: Foundation Models under Real-World Constraints**.

Cheng-Che Lee, Chia-Pin Cheng, Hsu-Sheng Chang, Chia-Lin Chou
Digital Innovation Laboratory, Chunghwa Telecom Laboratories, Taoyuan, Taiwan

[[Paper]](https://openreview.net/pdf?id=umdC2BfHOe) [[OpenReview]](https://openreview.net/forum?id=umdC2BfHOe)

**TL;DR:** A 2.3M-parameter router trained with zero real privacy-sensitive screenshots reaches 71.62% on
real-world screenshots, above four zero-shot sVLMs up to 1,800× larger (best: PaliGemma 2 3B, 57.98%).
